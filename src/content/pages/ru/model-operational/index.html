Данные до запуска

Рынок, построенный на современных технологиях

Платформа ARENA, разработанная BVB и эксплуатируемая по модели SaaS, использует принцип remote-first. Брокеры подключаются по защищённому каналу из собственных офисов.

Как это работает

Распределённая операционная модель между BVB, BIMx и брокерами.

Компонент Роль
BVB

Эксплуатирует платформу (хостинг, техническое обслуживание, ноу-хау)
BIMx

Администрирует рынок (правила, пользователи, взаимодействие с НКФР и ЕЦД)
Брокер

Обеспечивает доступ к рынку (клиенты, заявки, подключение)

Преимущества модели

Быстрый доступ — терминал GUI с момента запуска

Поэтапная автоматизация — Gateway API на второй год, FIX на третий год

Рыночные данные в режиме реального времени

Расчёты T+2 через Единый центральный депозитарий
